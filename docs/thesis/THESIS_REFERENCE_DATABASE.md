# SecureGate Thesis Reference Database

This database lists the academic papers, industry standards, and official documentation used for citations in the literature review and technical implementation chapters of the thesis.

---

## 1. Official Standards and Specifications

- **[Ref-1] JWT Specification (RFC 7519)**
  - **Authors**: Jones, M., Bradley, J. and Sakimura, N.
  - **Title**: JSON Web Token (JWT)
  - **Publisher**: IETF RFC 7519
  - **Year**: 2015
  - **URL**: https://tools.ietf.org/html/rfc7519
  - **Scope**: Used for authentication token structures and dynamic QR challenge tokens.

- **[Ref-2] Bcrypt Hashing Function**
  - **Authors**: Provos, N. and Mazières, D.
  - **Title**: A Future-Adaptable Password Scheme
  - **Conference**: USENIX Security Symposium
  - **Year**: 1999
  - **Scope**: Used for database-backed password storage encryption.

- **[Ref-3] HTTP/1.1 Protocol (RFC 7230)**
  - **Authors**: Fielding, R. and Reschke, J.
  - **Title**: Hypertext Transfer Protocol (HTTP/1.1): Message Syntax and Routing
  - **Publisher**: IETF RFC 7230
  - **Year**: 2014
  - **Scope**: Standards for REST API communication.
